# Orbit compliance checklist (India)

This product is built to follow the operating rules below. A lawyer and a CA still need to confirm entity, GST, and marketplace facts before commercial launch.

| Area | In the product |
| --- | --- |
| Business registration | Privacy Policy states MCA incorporation (Pvt Ltd / LLP / proprietorship) is required before commercial operation. Preview until then. |
| Terms | Separate **Terms of Use** (job seekers) and **Terms for employers**. |
| Privacy Policy | Lists candidate fields (resume fields, phone, email, education, work history, location) and who can see them. |
| Data protection | Designed around the DPDP Act, 2023 and DPDP Rules, 2025. |
| User consent | Apply sheet requires consent. Employers see a **masked** mobile, not the raw number. |
| Delete / account | Profile → Close account clears seeker data on device and signs out. Email `support@orbit.app` for erasure. |
| Security | Passwords via sign-in provider; sanitised apply fields; masked phones; role-based Super Admin; HTTPS for cloud writes. |
| Employer verification | Super Admin verifies recruiters. Unverified posters stay in review. |
| Fake-job prevention | Listings that charge registration / equipment / training / deposit / interview fees are blocked. |
| Misleading jobs | Salary, location, role, and employer identity are required; “Competitive” / “Negotiable” alone is rejected. |
| Complaints | Report job and Report employer on the listing. Grievance: `support@orbit.app`. |
| Payments | ₹25 extra posts and memberships; invoices/GST to be confirmed with a CA. CBIC e-commerce operator rules flagged in employer terms. |
| Employment regulations | Employer terms: posting on Orbit does **not** replace statutory vacancy-notification or other employer duties. |
